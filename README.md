# Портфолио веб-дизайнера

## Описание проекта
Учебный сайт-портфолио для демонстрации работ в области веб-дизайна и веб-разработки.

## Используемые технологии
- HTML5
- CSS3
- Git

## Возможности
- Краткое описание авААВАтора
- Список учебных работ
- Адаптивное оформление страницы

## Структура проекта
- `index.html` — основная страница сайта
- `style.css` — оформление сайта
- `.gitignore` — правила игнорирования ненужных файлов
- `README.md` — описание проекта

## Запуск проекта
Откройте файл `index.html` в браузере.

## Автор
Миржахон Миркадиров
1. Какие файлы войдут в репозиторий?
В репозиторий войдут файлы index.html, style.css, README.md и .gitignore. Они содержат структуру сайта, оформление, описание проекта и правила игнорирования ненужных файлов.
2. Почему файл test.log игнорируется?
Файл test.log игнорируется, потому что в файле .gitignore указано правило *.log. Оно запрещает Git отслеживать файлы с расширением .log, которые обычно содержат технические записи и не нужны в репозитории.
3. Какую информацию содержит README?
Файл README.md содержит название проекта, его описание, список основных файлов и информацию о том, как открыть и использовать проект. Он помогает другим разработчикам быстро понять назначение сайта.
4. Какие данные нельзя публиковать в открытом репозитории?
В открытом репозитории нельзя публиковать пароли, API-ключи, токены доступа, личные данные, конфиденциальные документы и другую информацию, которая должна оставаться секретной.
5. Готов ли проект к размещению на GitHub? Обоснуйте ответ.
Да, проект готов к размещению на GitHub, поскольку содержит необходимые файлы index.html, style.css, .gitignore и README.md. Также создан локальный Git-репозиторий, проверены игнорируемые файлы и сохранена версия проекта с помощью коммита. Перед публикацией необходимо убедиться, что в проекте нет конфиденциальных данных.
Сайт разработан в рамках практических занятий по Git.
