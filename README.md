# Портфолио веб-дизайнера

## Описание проекта
Учебный сайт-портфолио для демонстрации работ и практики подготовки Git-репозитория к размещению на GitHub.

## Используемые технологии
- HTML
- CSS
- Git

## Возможности
- Краткое представление автора
- Список учебных работ
- Адаптивное оформление для небольших экранов

## Структура проекта
- `index.html` — основная страница сайта
- `style.css` — стили и адаптивное оформление
- `.gitignore` — список файлов, которые Git должен игнорировать
- `README.md` — описание проекта и инструкция по запуску
- `screenshots/` — сюда можно сохранить скриншоты выполнения задания

## Запуск проекта
Откройте файл `index.html` в любом современном браузере.

## Проверка Git
```bash
git status
git check-ignore -v test.log
git log --oneline
```
